The denominator map: one year, many “denial rates”

Short answer. There is no single mortgage denial rate for a program and a year. The same public file gives figures from 10.6% to 60.4% for the programs below, depending on three choices: which loan purpose is counted, which applications are in the denominator, and whether a scope filter is applied. A figure quoted without those three is not wrong so much as unplaceable. This page shows every cell, so any figure can be placed.

The three denominators. Decisioned: originated, approved but not accepted, or denied (this site’s published definition). Acted on: decisioned plus withdrawn and closed-for-incompleteness files. Denied + originated: approvals the applicant did not accept are left out. Standard scope: first lien, owner-occupied principal residence, site-built, 1–4 units. Bold rows carry receipts; the other cells are a reference table from the same run.

Place a figure

Met a denial rate somewhere and cannot tell what it measures? Type it. The cells within 0.15 points are listed. A match is a match, not an attribution: it shows which definition can produce the number from the 2025 file, not which one its publisher used. No match means the figure comes from another year, another filter, or cannot be reproduced from this file.

What this page does not establish

  • Which denominator any other publisher used.
  • That purchase loans are easier to obtain than refinances, or one program easier than another: the applicant populations differ by eligibility and composition.
  • Any individual’s chance of denial, or any lender-level figure.
