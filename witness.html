Witness · for work handed to AI agents

A signed, dated record that the agent had the whole document

When an agent reports on a document, the party relying on the report cannot tell whether the agent saw all of it. A reading proof answers that, but only if someone other than the agent runs the check. This is that someone: the lines to quote are drawn here, the answers are checked here, and the result is signed, dated and chained to the one before it. A failed reading is recorded as carefully as a successful one.

Attestation

Who does what

  1. You, handing out the document, register its manifest here. The manifest is one short hash per line. The text is never sent, and the manifest is not shown to anyone afterwards.
  2. The agent states its finding to the witness. The witness draws six lines, one from each sixth of the document, using a number the agent could not know in advance.
  3. The agent answers once, within fifteen minutes. A line it does not have is answered with the word MISSING.
  4. The witness signs what happened: which document, the hash of the statement, when the lines were drawn, how many seconds the answer took, which parts were shown, and which draw this was for that statement. Anyone can check the signature.

Price

The first three witnessed readings of each document are free. After that, one prepaid credit per reading; a call without credit is answered with status 402 and a checkout link that a person has to confirm. Checking an attestation is always free, and so is everything else on this site.

What an attestation says and what it does not. It says that whoever answered could read the lines marked as shown, in the registered document, within the stated number of seconds after they were drawn. It does not say the statement is true, that the document was understood, or that every line was read: an agent with the file open can look up six lines. It does not say the registered manifest belongs to the document you think it does; compare the document id with your own. The witness keeps hashes, not text, and cannot reconstruct a document or a statement. If its key were lost or misused, attestations signed after that moment would be worthless; the chain makes later insertions visible, not impossible.
