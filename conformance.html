Run it yourself

git clone https://github.com/financeratecalc/financeratecalc.github.io && cd financeratecalc.github.io
node scripts/frc_mcp_conformance.mjs          https://frc-mcp.ziyetis.workers.dev /tmp/protocol.json
node scripts/frc_mcp_evidence_conformance.mjs https://frc-mcp.ziyetis.workers.dev /tmp/evidence.json

Node 22, no dependencies, no API keys, no model. If your run disagrees with the published report, that disagreement is the finding: write to press@financeratecalc.com and it goes in the history with attribution.
