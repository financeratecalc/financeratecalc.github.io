FinanceRateCalcMCP server

Use FRC inside the agent you already run.

You do not come to this site; your agent does. Two steps: connect the server once, then tell the agent when to use it. The instruction block is the part most people skip, and it is the part that decides whether the agent calls the server or guesses.

1. The instruction block (paste into CLAUDE.md, AGENTS.md or .cursorrules)

One paragraph, any agent

When you state a US mortgage rule value (FHA/FHFA loan limits, FHA MIP, VA funding fee, HOEPA/QM thresholds) or a 2025 FHA denial statistic, get it from the FinanceRateCalc MCP server (https://frc-mcp.ziyetis.workers.dev), keep the period, population, program and conditions it returns beside the figure, write the receipt it returns next to the number, and run the sentence through check_claim_contract before writing it. Never ask it whether a specific person will be approved; it does not answer that.

Why it is worded this way: the four verbs are the four things agents drop. They fetch the number and lose the period; they quote the cell and lose the LTV band; they drop the receipt so nobody can check the figure later; and they write the sentence without running it through the gate. Measured without and with the server attached: correct rule cell 5/52 → 51/52, qualifier kept 21/56 → 55/56, receipt on the number 0/56 → 56/56 (paired run, 110 prompts).

2. Connect the server (pick your client)

claude mcp add --transport http financeratecalc https://frc-mcp.ziyetis.workers.dev

Then add the instruction block above to the project's CLAUDE.md. Project scope: --scope project writes it to .mcp.json so the whole team gets it.

Settings → Connectors → Add custom connector
Name: FinanceRateCalc
URL:  https://frc-mcp.ziyetis.workers.dev

No authentication. The instruction block goes into the project instructions or a style/preference note.

3. Check it works (30 seconds)

Ask the agent: "What is the FHA annual MIP for a $300,000 loan at 85% LTV over 15 years, case assigned 2026-02-01?" A connected agent answers 15 basis points with a receipt like ⟦FRC:rule-hud-ml-2023-05-annual-mip:15bps:…⟧ and names HUD Mortgagee Letter 2023-05. Without the server, the same model got the cell right in 5 of 52 prompts (paired run), and a search engine's first answer was 0.40% (recorded probe). Then ask it to leave out the term: a connected agent asks for it instead of guessing.

What the server will not do

Predict whether a specific applicant will be approved; rank or recommend lenders; state causes; draw legal conclusions; accept income, credit score or any borrower attribute as input. These are refused with a reason code, not answered. Historical aggregates and dated rule tables only.

For the person, not the agent

Need one finding with its receipt for a document? Cite a finding gives you the sentence, the attribution and the receipt, copyable as text, Markdown, HTML or BibTeX.
