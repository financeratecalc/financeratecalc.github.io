# Agent skills published by FinanceRateCalc

Skills in the open `SKILL.md` format (agentskills.io). Install with any skills-aware agent, e.g.
`npx skills add financeratecalc/financeratecalc.github.io --skill fha-denial-statistics`.

| skill | what it does |
|---|---|
| `fha-denial-statistics` | Answer FHA denial questions from the 2025 HMDA record via the FRC MCP server or static JSON, inside the published use contract, carrying the claim receipt. |

Skills carry no data; they tell the agent where the data is and how the publisher asks for it to be restated.
