The 2027 limit race: which AI learns the new loan limits first?

On a known date every US loan limit changes. This page asks each reachable AI engine the same three questions every day, one fresh call each, and grades the answer against our dated rule files with fixed rules, no model in the loop. Before FHFA and HUD publish, the only correct answer is "not yet announced"; a 2027 figure given before then is invented. After publication, the correct answer is the published value, whose rule file carries a receipt and a transparency-log entry proving when it existed.
