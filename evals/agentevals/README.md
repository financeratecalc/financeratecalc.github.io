# frc-citation-decision — agentevals suite

An [agentevals](https://agentevals.pages.dev) `EVAL.yaml` built from FinanceRateCalc's [citation-decision fixtures](https://financeratecalc.com/fixtures/citation-decision/fixtures.json): 39 questions about 2025 FHA denial statistics and dated US mortgage rule cells. For each, the expected output is the genuine receipted sentence, and a `code_judge` (`judges/receipt_fidelity.py`, no model) scores the agent's answer: the published figure present (0.35), the claim receipt present and verifying as current (0.25), period and program kept (0.2), no individual prediction / lender recommendation / cause / legal conclusion (0.2, required). A value from a wrong candidate (wrong tier, wrong role, superseded, forged) scores 0.

Rebuilt by `scripts/build_agentevals.py` whenever the fixtures change. Point the target at any agent that can reach the [MCP server](https://financeratecalc.com/mcp-server.html) or read [llms-full.txt](https://financeratecalc.com/llms-full.txt); the judge needs Python 3 and, for live verification, network access to `frc-mcp.ziyetis.workers.dev` (without it, receipt presence is credited and verification is reported as not performed).
