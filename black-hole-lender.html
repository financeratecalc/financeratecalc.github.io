Highest-denial cells by lender, 2025: a provisional research note

Provisional. Not receipted. Do not cite as a finding. These six figures were computed once in 2026 from the 2025 HMDA loan-level file. The script that produced them is not in this site’s published code, so the site cannot reproduce them today. They stay here, relabelled on 28 November 2026, so that anyone who read or cited the earlier page “The Black Hole Lender” can see what it said and what is wrong with it.

For each of six lenders, the cell of debt-to-income ratio and combined loan-to-value with the highest denial rate among cells with at least 50 applications, as recorded in _data/black_hole_2025.json. Lenders in alphabetical order.

What is wrong with these figures, or not yet shown

  • Chosen as the highest. Each figure is the highest of many cells for its lender, some with only 63 applications. The highest of many small cells looks more extreme than the lender’s record is. The earlier page did not say how many cells were compared.
  • Not the same applicants. The earlier page compared lenders as if they faced “the same profile”. The cells it compared are different cells: PennyMac’s is DTI 36–38 with CLTV 100–105, CrossCountry’s is DTI 48–50 with CLTV 80–85.
  • Inconsistent with itself. The earlier page said 248 of 249 PennyMac applications in its cell were denied (99%). Its own data file says 98.8%, which is 246 of 249.
  • Method not checkable. The method line named a loan-product code (“2 or 32”) that is not how the public file marks FHA loans, and counted only originated and denied applications. Without the script, it cannot be told which records were used.
  • Cause not shown. The earlier page called these zones lender overlays. The record shows how many applications were denied, not why. Part of a high-CLTV cell can come from program limits rather than a lender’s choice.
  • Not about one file. A cell’s rate describes the applications that lender received. It does not say how the lender would decide one application, and it is not a reason to choose or avoid a lender.

What would make these citable: the same cells recomputed from the public file by a published script, with the number of cells compared, at least 100 applications per cell, and a receipt for each figure. Until then this note stays provisional. The paid report built on these cells and the page that sent readers to other lenders are retired; the corrections log records why.
