This page has been retired.

This page, shown to search engines, documented the OFI data files as a public API. The site’s figures with receipts are served by its tool server and listed in the data catalog. It was part of the Overlay Friction Index (OFI) family, published from May 2026. The index’s historical values, which its forecasting model was trained on, are typed into the model’s code with no source; its methodology said it was recalculated from HMDA releases, which are annual and cannot give quarterly values. A figure that cannot be traced to a source is not published on this site. The page was withdrawn on 28 November 2026 and now records that.

What this site does instead: it shows what the record supports and where the evidence ends — The Denial Map · FHA denial rates by lender, with receipts · Official figures · Corrections log.

The data behind everything remains free.
